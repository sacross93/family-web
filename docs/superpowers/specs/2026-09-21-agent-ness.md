# 포동이는 "에이전트" 인가 — 모자란 것 목록과 순서

2026-09-21. 물음은 하나였다: **"ai agent 답게 되어 있나?"**

## 지금 무엇인가

**도구를 쥔 대화 상대**다. 잘하는 것이 분명히 있다 — 목차로 사이트 전체를 훑고,
16종을 펼쳐 읽고, 14종을 대신 적어 주고, 바깥 주소를 직접 열어 읽는다.
**정직함은 이미 설계에 박혀 있다**: 읽은 것과 검색한 것을 섞지 말라고 규칙이 강제하고,
못 읽은 것은 `ok` 를 주지 않으며, 추가한 것마다 되돌리기가 붙는다.

모자란 것은 **능력**이 아니라 **주체성**이다. 지금 포동이는

- 자기가 **누구와 어디서** 이야기하는지 모르고,
- 대화가 끝나면 **다 잊고**,
- 자기가 한 일이 **정말 됐는지 확인하지 않고**,
- **부르지 않으면 아무것도 하지 않는다.**

그래서 "무엇이든 물어보세요" 라고 떠 있지만, 실제로는 **매번 처음 만나는 사람**이다.

## 목록 (순서대로 하나씩)

순서의 기준은 **가족에게 오늘 느껴지는가 × 값이 싼가**다. 위에서부터 판다.

- [x] **1. 지금 어디를 보고 있는지 안다.** ✅ 2026-09-21
      `view_screen` 은 다섯 도구 중 하나로 선언돼 있으면서 **언제나 "아직 지원하지 않습니다"**
      를 돌려줬다 — 모델이 그걸 한 번 부르면 여섯 걸음 중 한 걸음이 그냥 사라진다.
      화면 위치는 도구로 물을 것이 아니라 **처음부터 알고 있어야 하는 것**이다.
      → 죽은 도구를 걷어내고(5개→4개) 현재 경로를 안내문 맨 앞에 싣는다. 모델 호출 0회 추가.
      메뉴 9개 화면 전부 + 홈(`/`) 을 알아본다. 등록 안 된 경로는 라우트와 `screenLine`
      **두 곳에서** 버린다 — 안내문에 글로 들어가는 자리라 임의 문자열이 지시로 읽힌다.
- [x] **2. 만든 것을 되읽어 확인한다.** ✅ 2026-09-21
      지금은 `POST` 가 200 을 주면 "다 했어요" 라고 말한다. 서버가 저장을 안 했어도
      같은 말을 한다. 더 나쁜 쪽은 **조용히 빠지는 값**이다 — 라우트가 모르는 필드를
      버리면 "내일 우유 사기" 가 날짜 없이 저장되고도 200 이 온다.
      → 만든 뒤 `catalog()` 에서 그 id 를 찾아 `stored` 에 싣고, **화면 카드도 그 값**을 쓴다.
      추가 모델 호출 0회. 못 찾아도 실패로 돌리지 않는다(그러면 중복 생성).
- [x] **3. 남는 기록(`AgentRun`).** ✅ 2026-09-21 표는 있는데 쓰는 코드가 한 줄도 없다.
      무엇이 왜 실패했는지 볼 데가 없으면 나머지 항목을 고쳐도 확인할 수가 없다.
      → **도구 이름·성패·label·걸린 시간까지만.** `ToolResult.data` 도 도구 오류 문구도
      공급자 오류 본문도 넣지 않는다(바깥 글과 가족 데이터가 로그에 눌러앉는다).
      거르는 곳은 `shapeRun()` 하나. 30일치만 두고(무료 티어), 보는 법은 `npm run agent:runs`
      — 표만 만들고 읽을 길이 없으면 없는 것과 같다.
- [x] **4. 도구 결과 본문 줄이기.** ✅ 2026-09-21 `loop.ts` 가 `JSON.stringify(result)` 를 통째로 대화에
      넣는다. (처음에 근거로 적었던 8,697px 짜리 말풍선은 **도구 결과가 아니라 모델이 쓴 답**
      이었다 — 4,140자. 재 보고 고친다.) **진짜 근거는 따로 있었다**: 8,000자짜리 게시판 글
      다섯 개를 심으니 `list_resource` 하나가 647자 → **39,117자**가 됐다. 목록 상한이 30개라
      여기서 더 간다. 바깥 웹 한 쪽엔 6,000자를 주면서 우리 목록은 무제한이었던 셈이다.
      → 목록 본문에 예산(`budgetBodies`), 루프에 마지막 안전장치(`serializeResult`).
      같은 데이터로 **39,117자 → 5,757자.** 덤으로 `budget()` 의 묵은 버그를 하나 잡았다 —
      상한이 300자보다 작고 문장 부호가 없으면 **본문이 통째로 사라지고 꼬리표만** 남았다.
- [x] **5. 대화가 끝나도 기억한다.** ✅ 2026-09-21 — ⚠️ 배포 전 `prisma db push` 필요 지금 기억은 한 대화 안 10개뿐이다.
      → **`memory` 리소스**(도구가 아니라 리소스 — 규칙은 "새 기능이면 리소스를 추가").
      **목차에는 안 넣었다**(`inCatalog:false`): 목차는 "사이트에 뭐가 있나" 고 기억은
      "내가 아는 것" 이라, 같은 4,000자를 두고 다투면 글이 늘어난 날 기억이 조용히 접힌다.
      안내문에 제 몫의 칸(600자)으로 들어간다. 누가 적었는지(`by`)를 늘 함께 보여 준다 —
      포동이가 짐작한 것과 가족이 말해 준 것이 같아 보이면 잘못된 기억이 사실처럼 굳는다.
      가족은 `/memories` 에서 직접 지운다(고치는 도구는 없다).
- [x] **6. 누가 말하는지 안다.** ✅ 2026-09-21 계정이 하나(`wlsdud022`)라 세션으로는 알 수 없다.
      단서는 이미 있다 — 아기 기록이 마지막 작성자를 `podong_baby_author` 에 기억한다.
      → 기기에 한 번 고른다(포동이 빈 화면의 "나는 ___", 열쇠 `podong_me`). 아기 기록에서
      작성자를 고르면 같은 값이 따라 적힌다 — 이미 말해 준 것을 또 묻지 않으려고.
      라우트가 **실제 가족 명단과 맞춰 본 이름만** 넘기고, 안내문은 "확실하지 않다"와
      "무엇으로 적었는지 밝혀라"를 함께 강제한다. 이름만 주면 모델은 사실로 쓰고,
      아빠 폰을 엄마가 들면 **틀렸다는 것을 아무도 모른다.**

## 의도적으로 하지 않는 것

여기 적어 두는 이유: 다음 판에 "에이전트라면 당연히…" 하고 **되살리지 않기 위해서**다.

- **수정·삭제 도구를 만들지 않는다.** 모자라서가 아니라 정한 것이다(AGENTS.md).
  되돌릴 수 있는 추가만 맡기고, 되돌릴 수 없는 일은 가족이 직접 누른다.
- **먼저 말 거는 포동이(스케줄·알림)를 만들지 않는다.** 가족의 개인 ChatGPT 사용량을
  **허락 없이** 쓰게 된다. 하고 싶으면 그것부터 물을 것.
- **헤드리스 브라우저를 넣지 않는다.** 실측으로 이미 정리됐다
  (`2026-09-20-web-reading-findings.md`).
- **도구를 늘리지 않는다.** 새 기능은 리소스로 들어온다. 1번은 오히려 하나 **줄인다.**

## 여섯 개를 다 한 뒤

2026-09-21에 목록이 다 찍혔다. 무엇이 달라졌는지 한 줄씩:

| 전 | 후 |
|---|---|
| 다섯째 도구가 늘 "지원 안 함" 만 돌려줬다 | 도구 4개가 전부 살아 있고, 화면 위치는 안내문이 준다 |
| 200 이면 "다 했어요" | 되읽어 본 **저장된 모습**을 보고 말한다 |
| 무엇이 왜 실패했는지 볼 데가 없었다 | `npm run agent:runs` |
| 목록 하나가 39,117자까지 갔다 | 세 겹으로 막아 5,757자 |
| 대화를 닫으면 다 잊었다 | `/memories` 에 남고, 가족이 지운다 |
| 누가 말하는지 몰랐다 | 기기에 고른 사람을 **짐작이라고 밝히며** 쓴다 |

다음에 무엇을 할지는 **여기 적지 않는다.** "의도적으로 하지 않는 것" 을 먼저 읽고,
그래도 할 것이 있으면 그때 새 목록을 만든다.

## 한 판에 하나씩

이 목록은 판이 바뀌어도 남으라고 파일로 적었다. 한 판의 일은
**다음 안 찍힌 칸 하나** — 구현 → `npm test`·lint 0·tsc → 커밋 → 푸시 → 칸 찍기.
두 개를 한꺼번에 하지 않는다.

**칸이 다 찍혔으면 그 판의 일은 「보고」다.** 코드를 열지 않는다.
"에이전트라면 이것도…" 가 떠오르면 먼저 위의 **의도적으로 하지 않는 것**을 읽고,
그래도 남으면 **새 파일**을 만든다 — 이 파일에 칸을 더하지 않는다.
다 찍힌 목록에 칸을 더하기 시작하면 끝이 없고, 무엇이 끝났는지도 알 수 없게 된다.
