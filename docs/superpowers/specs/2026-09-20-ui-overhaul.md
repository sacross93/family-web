## 실측 (2026-09-20, 로컬 시드 데이터, 390px / 1280px)

가로 스크롤은 12개 페이지 × 2폭 = 24장 전부 0px. 모바일 규칙의 이 항목은 지켜지고 있다.

| # | 문제 | 증거 |
|---|---|---|
| 1 | 모바일 네비가 햄버거 뒤에 있다 | 9개 섹션 전부 "햄버거 → 항목" 2탭 |
| 2 | FAB 2개가 모든 페이지에서 콘텐츠를 가린다 | 홈·기념일·장보기·할일에서 확인. 열린 드로어 위에도 뜬다(z-index) |
| 3 | 빈 카드가 가득 찬 카드와 같은 높이를 차지한다 | 모바일 홈 2,093px = 2.5화면, 8카드 중 3개가 빈 상태 |
| 4 | 기념일이 같은 항목을 두 번 보여준다 | "다가오는 D-day" 3건이 "전체 기념일" 6건에 그대로 다시 — 2,300px |
| 5 | 콘텐츠 전 상단 크롬이 두껍다 | 앱바 + PageHeader(이모지·제목·설명) + 액션 = 약 230px |
| 6 | 수정·삭제 아이콘이 항상 떠 있다 | 기념일 6건 = 아이콘 버튼 12개 |
| 7 | 장보기 폼이 목록을 밀어낸다 | 첫 항목까지 약 290px. 마트에서 필요한 건 목록이다 |
| 8 | 모바일 드로어가 Escape 로 닫히지 않는다 | 실측 — 오버레이 클릭만 먹는다 |
| 9 | 데스크톱 "최근 사진"이 오른쪽에서 잘린다 | 스크롤 여지 표시 없이 사진 중간에서 끊김 |
